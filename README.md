# Spring AI Tutorial

Spring AI를 활용하여 **LLM 호출과 RAG 파이프라인 구축**을 학습하는 Kotlin + Spring Boot 실습 프로젝트입니다.


- Kotlin `1.9.25` / Spring Boot `3.5.7` / Spring AI `1.0.3` / Java `21`

- Spring AI를 이용한 OpenAI 모델 호출  (`chapter1_exercise`, `chapter1_completed`)

- RAG 파이프라인 설계 및 구현  (`chapter2`)


```bash
# 프로젝트 빌드
./gradlew build

# 애플리케이션 실행
./gradlew bootRun
```

애플리케이션이 성공적으로 시작되면 다음 주소에서 접근 가능합니다.

- **메인 서버**: http://localhost:8080
- **Swagger UI**: http://localhost:8080/swagger-ui.html
